# ST Web & Innovation — GitHub Pages Website

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year, and WhatsApp enquiry form

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_NUMBER_HERE` with your WhatsApp number.
3. Change any business wording you want in `index.html`.
4. Add your real portfolio projects when you have them.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your free `github.io` website address.

You can later connect a custom domain after the business starts earning money.
