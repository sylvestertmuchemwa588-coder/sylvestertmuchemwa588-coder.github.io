# ST Web & Innovation — Digital V3

V3 adds real visual sections, developer/business photography, interactive industry cards, detailed website-type explanations, and a WhatsApp build-brief generator.

Upload index.html, style.css and script.js to the root of your GitHub Pages repository.

IMPORTANT: In script.js replace YOUR_NUMBER_HERE with your WhatsApp number in international format, without + or spaces. Example format: 2782XXXXXXX.

The site uses Unsplash image URLs, so images require an internet connection. The industry examples are concepts/templates, not claimed client projects.
