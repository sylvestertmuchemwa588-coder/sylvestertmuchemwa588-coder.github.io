# ST Web & Innovation V4

Professional website for ST Web & Innovation.

## Files

- `index.html` — Main website structure and content.
- `style.css` — Website design, layout, responsive/mobile styling, and animations.
- `script.js` — Interactive menu, business package selection, form handling, and WhatsApp message generation.
- `README.md` — This guide.

## How to replace the old website

1. Open your GitHub repository:
   `sylvestertmuchemwa588-coder.github.io`
2. Replace the old `index.html` with the new `index.html`.
3. Replace the old `style.css` with the new `style.css`.
4. Replace the old `script.js` with the new `script.js`.
5. Upload `README.md`.
6. Commit the changes.
7. Wait a short while for GitHub Pages to update.

## IMPORTANT: Add your WhatsApp number

Open `script.js` and find:

    const ST_WHATSAPP_NUMBER = "27821234567";

Replace the example number with your own South African WhatsApp number.

Use international format:

    27XXXXXXXXX

Do NOT include:

- `+`
- spaces
- brackets
- hyphens

Example format:

    const ST_WHATSAPP_NUMBER = "27821234567";

## How the customer system works

1. Customer visits the website.
2. Customer chooses their business type.
3. The selected starting package is placed into the request form.
4. Customer enters their business information.
5. Customer describes the website they want.
6. The website generates a structured WhatsApp project brief.
7. WhatsApp opens with the message prepared.
8. Customer reviews the message and sends it to ST Web & Innovation.
9. ST Web & Innovation can then discuss the project and give a final quotation.

## GitHub Pages

This project is designed to work as a static GitHub Pages website. It uses HTML, CSS and JavaScript and does not require a separate server for the customer enquiry form.

A custom `.co.za` domain is not required to start. You can use the free GitHub Pages address while building your customer base and purchase/connect a custom domain later.

## Important note about WhatsApp

The website does not automatically send a WhatsApp message without the customer's action. It prepares the message and opens WhatsApp so the customer can review it and press Send.
