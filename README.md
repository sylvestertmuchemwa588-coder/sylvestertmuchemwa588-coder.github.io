# ST Web & Innovation V5

A more visual, scrollable version of the ST Web & Innovation business website.

## Files
- `index.html` — website structure and content
- `style.css` — design, layout and mobile responsiveness
- `script.js` — menu, package selection and WhatsApp request generator
- `README.md` — setup guide

## Replace the old site
Replace the existing `index.html`, `style.css` and `script.js` in your GitHub repository with these files. Upload this README too.

## IMPORTANT: WhatsApp number
Open `script.js` and change:
`const ST_WHATSAPP_NUMBER = "27821234567";`

Use your real number in international format without `+`, spaces or brackets.

## Images
This version uses online Unsplash photography for the hero, business categories and portfolio examples. Internet access is required for those images to load.

When you have your own approved business or portfolio photos, put them in an `images` folder and replace the image URLs in `index.html` with local paths.

## Customer journey
1. Customer chooses a business type.
2. The site shows a photo and starting price.
3. Customer clicks Choose.
4. The selected package is placed into the request form.
5. Customer describes the business and requested features.
6. The site creates a structured WhatsApp project brief.
7. WhatsApp opens so the customer can review and send it.
